ポジティブフィンガー™

言葉から、コミュニケーションを変えていく。

01 / OVERVIEW

プロジェクト概要

誹謗中傷が広がるネットの世界を、ポジティブな言葉が広がる世界へ。

ポジティブフィンガー™は、スマートフォンでの文字入力を通じて、 ポジティブな言葉や表現を広げることを目指すプロジェクトです。 日常的なコミュニケーションの中に前向きな言葉を増やし、 より良いネットコミュニケーションの実現を目指します。

02 / SOCIAL ISSUE

解決したい課題

SNSやインターネット上では、誹謗中傷や否定的な言葉が 社会的な問題となっています。 私たちは、否定的な言葉を減らすことだけでなく、 ポジティブな言葉を積極的に増やすことにも着目しました。

誹謗中傷・攻撃的な言葉

ネット上での否定的なコミュニケーションが人々に与える影響。

ポジティブな言葉の不足

相手を認めたり、応援したりする表現を広げる機会。

日常的な行動へのアプローチ

普段の文字入力からコミュニケーションを見直す仕組み。

03 / FEATURES

主な機能

FEATURE 01

キーボード連携

専用キーボードを通じて、普段の文字入力にポジティブフィンガー™の仕組みを取り入れます。

FEATURE 02

ポジティブ判定

入力された文章に登録済みのポジティブな言葉や表現が含まれるかを判定します。

FEATURE 03

ポイントシステム

ポジティブな言葉の使用に応じてポイントを獲得する仕組みです。

FEATURE 04

継続的な参加

日々の文字入力を通じて、前向きなコミュニケーションを意識するきっかけをつくります。

04 / SYSTEM

システムの仕組み

文字入力から文章の判定、ポイントの反映までを連携させます。

文字を入力→ 文章を確定→ ポジティブ判定→ ポイント反映
05 / DEVELOPMENT

開発について

ポジティブフィンガー™は、Can go→の最初のプロジェクトとして、 学生メンバーと担当教員によって企画・開発を進めています。 実際に利用できるアプリケーションを目指し、 試作・検証・改善を繰り返しています。
