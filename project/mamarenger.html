01 / OVERVIEW

プロジェクト概要

書くことから始まる、子育て支援。

ママレンジャーナリングは、子育て中の人が日々の気持ちや悩みを 安心して書き出せる場所をつくることを目指すプロジェクトです。 相談するほどではないけれど、誰かに聞いてほしい。 そんな気持ちを匿名で記録し、子育て経験のあるサポーターが受け止める。 書くことをきっかけに、人と人、そして地域の支援をつなぐ仕組みを構想しています。

02 / SOCIAL ISSUE

解決したい課題

子育てには喜びだけでなく、不安や孤独、疲れなど、 さまざまな感情があります。 しかし、その声が周囲に届かないままになってしまうこともあります。 私たちは、日々の小さな気持ちを受け止める仕組みに着目しました。

ISSUE 01

相談するハードル

相談窓口に連絡するほどではないと感じ、 気持ちを抱え込んでしまう。

ISSUE 02

時間や環境の制約

子育てや家事に追われ、 自分の気持ちと向き合う時間が少ない。

ISSUE 03

声が届きにくい

日々の小さな悩みや気づきが、 支援する側に届きにくい。

03 / PROJECT FEATURES

主な仕組み

書くこと、人が受け止めること、そして必要な支援につなぐこと。 それぞれの役割を組み合わせた子育て支援の仕組みを構想しています。

FEATURE 01

匿名ジャーナリング

ニックネームで参加し、日々の気持ちや悩みを自由に記録。 文字だけでなく音声入力にも対応することを想定しています。

FEATURE 02

ママレンジャー

子育て経験のある人がレンジャーとして参加。 投稿者の気持ちを受け止め、1日1通を目安に メッセージを届ける仕組みを想定しています。

FEATURE 03

AIによるサポート

AIが投稿や返信の安全確認、緊急性の確認などを補助。 AI自身が相談相手になるのではなく、 人による対応を支援する役割を想定しています。

FEATURE 04

地域の声を未来へ

個人が特定されないよう配慮して声を集約し、 地域の子育て支援や施策の改善に 役立てることを目指します。

04 / SYSTEM

利用の流れ

気持ちを書き出すところから、必要な支援につながるまで。 人によるサポートを中心とした仕組みを目指します。

05 / MAMA RANGER

ひとりじゃない。
受け止めてくれる人がいる。

ママレンジャーは、
子育ての経験を持つサポーター。

子育てを経験した人が、今まさに子育てをしている人の 気持ちを受け止める。 専門家による相談とは異なる、 経験者同士だからこそ生まれるつながりを大切にします。 参加者には研修や利用規約を設け、 安心して活動できる仕組みを検討します。

06 / SAFETY & PRIVACY

安心して利用できる仕組みへ。

気持ちを安心して書き出せる場所にするために、 プライバシーと安全性を大切にします。

匿名での参加

ニックネームで利用できる仕組みを想定。 個人情報の取り扱いにも配慮します。

1対1の非公開コミュニケーション

投稿と返信は公開の場ではなく、 個別のやり取りを基本とする構想です。

AIによる安全確認

有害な表現や緊急性の高い投稿を確認し、 人による適切な対応を補助します。

必要な相談先への接続

専門的な対応が必要な場合には、 適切な相談窓口への接続を目指します。

07 / FOR MIYAZAKI

宮崎の子育てを、もっと支えやすく。

一人ひとりの声には、地域の子育て環境をより良くする ヒントが隠れています。 ママレンジャーナリングは、日々の小さな声を 地域の支援につなげることを目指します。

書くことから始まる、
宮崎の子育て支援。

個人の気持ちを大切にしながら、 地域全体で子育てを支える新しい仕組みへ。

08 / DEVELOPMENT

プロジェクトのこれから

構想から、実現へ。
